# Section 504. Indexing by Recording Officer.--The recorder shall index each declaration against the maker thereof as the grantor and the name by which the property is identified therein as the grantee. The recorder shall index each declaration plan and code of regulations and any revocation in the name by which the property is identified therein in both the grantor index and the grantee index. The recorder shall index each unit deed and mortgage and lease covering a unit in the same manner as like instruments are indexed.
