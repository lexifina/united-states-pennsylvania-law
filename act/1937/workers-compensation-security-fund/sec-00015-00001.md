# Section 15.1. All assets, moneys, securities, reserves, surplus liabilities and the like presently in either the Stock Workmen's Compensation Security Fund or the Mutual Carrier and Reciprocal Exchange Workmen's Compensation Security Fund shall forthwith be transferred to the single Workers' Compensation Security Fund created hereby.
(15.1 amended Apr. 13, 1988, P.L.344, No.48)
