# Section 1118-A. Recounts.--In an election district using an electronic voting system, should a recount of votes be ordered as provided by law, the ballots shall be recounted in accordance with section 1404(e). If the recount is conducted under Article XVII:
(1) If the election district uses an electronic voting system utilizing paper ballots, section 1701 shall apply.
(2) If the election district uses any other type of electronic voting system, section 1702 shall apply.
(1118-A amended Oct. 8, 2004, P.L.807, No.97)
