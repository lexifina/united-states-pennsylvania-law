# Section 1937. State System of Higher Education.
The following shall apply to appropriations for the State System of Higher Education:
(1) The sum of $5,000,000 is included in the appropriation, which shall be disbursed by the State System of Higher Education to the institution established under section 2002-A(a)(3) of the Public School Code of 1949, to develop and implement an enhanced transfer and workforce development initiative in partnership with a community college.
(2) (Reserved).
(1937 added Nov. 12, 2025, P.L.156, No.45)
