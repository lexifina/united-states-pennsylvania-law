# Section 3002. Constitutional Construction.--If any word, phrase, clause, sentence, section or provision of this code is for any reason held to be unconstitutional, the decision of the court shall not affect or impair any of the remaining provisions of this code. It is hereby declared as the legislative intent that this code would have been adopted had such unconstitutional word, phrase, clause, sentence, section or provision thereof not been included herein.
(3002 renumbered from 1202 Dec. 21, 1981, P.L.482, No.141)
