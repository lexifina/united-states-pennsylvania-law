# Pennsylvania law in git

Part of [lexifina/global-law](https://github.com/lexifina/global-law), one git history for every country's law: this is the law of Pennsylvania, United States, which global-law reads at `united-states/pennsylvania/acts/`.

This repository contains the Constitution, 52 Pennsylvania Consolidated Statutes titles with section text, and six unconsolidated statutes published by the Pennsylvania General Assembly. It has one available current-text version per act, not a reconstructed amendment history. The unconsolidated statutes are the Landlord and Tenant Act of 1951, Payment of the Wages of Labor (1859), Employment of Labor Regulated (1887), Liquor Code (1951), Pennsylvania Labor Relations Act (1937), and Pennsylvania Labor Mediation Act (1937).

The Consolidated Statutes use one file per section. Each of the six unconsolidated statutes uses one file containing the official HTML body's visible text in reading order, including textual supplementary matter. Publisher section-code markers that are hidden in the HTML are excluded. The legal text comes from the Pennsylvania General Assembly's Legislative Data Processing Center at palegis.us.

Each version is labelled as the oldest available current text. The six unconsolidated acts use source-based dates described in their version records. The earlier Consolidated Statutes titles have compilation-stamp or retrieval dates whose relationship to amendment commencement remains under review. These dates should not be read as a complete legislative history.

The corpus excludes regulations, court decisions, and most unconsolidated statutes. This is not an official publication or legal advice.
