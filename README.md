# Pennsylvania law in git

Part of [lexifina/global-law](https://github.com/lexifina/global-law), one git history for every country's law.

This repository contains 3,810 acts: 3,510 current-text acts (the Constitution, 52 consolidated statute titles with section text, and 3,457 unconsolidated acts), plus 300 separately published amendment instruments, as enacted, with source-based approval and commencement dates.

The official text comes from the Pennsylvania General Assembly, Legislative Data Processing Center. Consolidated statutes and most unconsolidated acts use one file per section. Each amendment instrument uses one file preserving the complete visible source text, including legislative brackets and textual tables.

Current-text versions are labelled as the oldest available text. Their compilation-stamp or retrieval dates remain under review and do not establish a complete legislative history. Amendment instruments complement these texts and do not reconstruct earlier consolidated wording. Instruments with mixed, conditional, unclear, or future commencement are excluded from this addition.

Regulations and court decisions are excluded. This is not an official publication or legal advice.
