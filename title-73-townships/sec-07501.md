# § 7501. Definitions.
The following words and phrases when used in this chapter shall have the meanings given to them in this section unless the context clearly indicates otherwise:
"Pennsylvania Construction Code Act." The act of November 10, 1999 (P.L.491, No.45), known as the Pennsylvania Construction Code Act.
"Uniform Construction Code." The Uniform Construction Code adopted under section 301 of the Pennsylvania Construction Code Act.
