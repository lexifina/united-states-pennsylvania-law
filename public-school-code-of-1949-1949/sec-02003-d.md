# Section 2003-D. Additional report requirements.
In addition to the requirements in section 2002-D relative to any appropriation, the report covering the 12-month period shall include for all programs of the university:
(1) Minimum number of credits required for a baccalaureate degree and for a master's degree.
(2) Number of bachelor's degrees, master's degrees, first professional degrees and doctoral degrees awarded for the previous five years and those estimates for that year.
(2003-D added July 9, 2008, P.L.846, No.61)
